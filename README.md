# 💼 Salary Prediction using Machine Learning

## 📌 Project Overview
This project is a Machine Learning-based web application that predicts the salary of developers based on various factors such as experience, education, and other inputs.

The model is trained on real-world survey data and deployed using an interactive Streamlit interface.

---

## 🚀 Features
- Predict salary based on user inputs
- Interactive web interface using Streamlit
- Data preprocessing and feature engineering
- Multiple ML models tested and best model selected
- Real-time prediction system

---

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Matplotlib / Seaborn (if used)

---

## 📊 Dataset
- Source: Stack Overflow Developer Survey 2023 1  
- Includes features like:
  - Years of experience  
  - Education level  
  - Programming languages  

---

## ⚙️ How It Works
1. Data preprocessing (cleaning, encoding)
2. Feature selection
3. Model training using regression algorithms
4. Model evaluation
5. Deployment using Streamlit
